# SlideForge Frontend (React + Vite)

Dev quickstart
--------------

1) Start backend API (in repo root):
   - make start-api

2) Install and run frontend:
   - cd frontend
   - npm install
   - npm run dev

3) Open http://localhost:5173
   - Configure API base URL via `.env` (see `.env.example`).

Build
-----

- npm run build
- Static assets output to `frontend/dist/`

Pages
-----

- Upload: upload a file, pick config path, toggle auto-fix, see report.
- From URL: evaluate a single URL or crawl a page for files, filter by extensions.

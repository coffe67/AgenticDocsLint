Curated Static Examples
=======================

This folder contains small, versioned examples that are kept under version control. Use them for predictable demos and tests without generating content.

Files
-----

- deck_curated.json: Minimal 4-slide deck covering Introduction, Methodology, Results, Conclusion.
- deck_curated.md: Markdown equivalent of the curated deck.

Usage
-----

- Run with default rules:
  - slideforge run --input examples_static/deck_curated.json --config config/default.yaml --out build_static --auto-fix
